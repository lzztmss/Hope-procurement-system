# 重构测试版运行说明

## 环境隔离

| 项目 | 本地测试版 | 重构测试版 |
| --- | --- | --- |
| 代码目录 | `/Users/ken/工作/采购系统/采购系统本地测试版` | `/Users/ken/工作/采购系统/采购系统重构测试版` |
| Git 分支 | `codex/procurement-workflow` | `codex/database-modularization` |
| 地址 | `http://127.0.0.1:8787` | `http://127.0.0.1:8788` |
| 数据库 | `xlx_local` | `xlx_refactor` |

两套环境必须始终使用不同端口和不同数据库。不要将重构版的 `.env` 复制回本地测试版。

## 启动重构测试版

```bash
cd "/Users/ken/工作/采购系统/采购系统重构测试版"
npm ci
npm start
```

启动后访问 `http://127.0.0.1:8788`。健康检查地址为：

```bash
curl http://127.0.0.1:8788/api/health
```

返回中的 `mode` 应为 `refactor-test`。

## 当前结构

- `server.js`：应用启动、静态文件和路由装配。
- `routes/`：认证、库存、单据读取和兼容状态接口。
- `lib/`：数据库访问、关系表同步、库存事务、单据读取。
- `app/js/api-client.js`：浏览器端唯一的 HTTP 请求入口。

## 已事务化的关键流程

1. 采购确认到货：库存、库存流水、采购状态、在途数量和关联订单同步更新。
2. 交付确认出库：库存、库存流水、交付状态及关联订单/换货售后同步更新。

这些操作不能通过手工修改状态替代。

## 数据库备份与回退

在进行大改前备份重构测试库：

```bash
/Applications/Postgres.app/Contents/Versions/latest/bin/pg_dump -Fc xlx_refactor -f /tmp/xlx_refactor_backup.dump
```

重构失败时，停止 8788 服务后再恢复到新建数据库；不要覆盖 `xlx_local`。
