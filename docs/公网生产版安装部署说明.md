# 心连心智能养老业务运营系统公网生产版安装部署说明

上海海魄信息科技股份有限公司  
心连心智能养老业务运营系统  
版本：公网生产版 1.0.0  
日期：2026-07-10

## 1. 适用场景

本版本用于长期正式使用，支持公司员工和领导通过电脑端、手机端在公网 HTTPS 下访问系统。

- 电脑端查询、管理、导出
- 手机端按权限录入、处理、查看
- 领导手机端和电脑端查看项目、库存、采购、交付、售后情况
- PostgreSQL 集中保存业务数据和员工账号
- Nginx 提供公网 HTTPS 访问
- Node.js 只监听服务器本机地址，不直接暴露公网
- 每日数据库备份，支持恢复

## 2. 推荐服务器

| 项目 | 建议 |
|---|---|
| 操作系统 | Ubuntu Server 24.04 LTS 或 26.04 LTS |
| CPU | 2 核起步，正式建议 4 核 |
| 内存 | 4GB 起步，正式建议 8GB |
| 磁盘 | 80GB 起步，正式建议 100GB 以上 |
| 数据库 | PostgreSQL 16 或以上 |
| 运行环境 | Node.js 20 或以上 |
| 网关 | Nginx |
| 域名 | 建议使用公司子域名，例如 ops.hope-m.com |

如果服务器部署在中国大陆，公网域名访问通常需要完成 ICP 备案。

## 4. 快速安装

上传安装包到服务器并解压：

```bash
tar -xzf 心连心智能养老业务运营系统_公网生产版_20260710.tar.gz
cd 心连心智能养老业务运营系统_公网生产版_20260710
```

执行安装：

```bash
sudo DOMAIN=ops.example.com bash scripts/install_ubuntu.sh
```

安装脚本会完成：

- 安装 Node.js、PostgreSQL、Nginx、Certbot
- 创建 PostgreSQL 数据库和数据库用户
- 生成 `.env`
- 导入初始业务数据
- 安装 systemd 服务
- 启动系统内部服务

脚本执行结束后会输出初始密码。初始账号默认使用这一个密码，首次登录后必须修改管理员密码，并修改或禁用不需要的演示账号。

## 5. Nginx 和 HTTPS

把域名 DNS 解析到服务器公网 IP 后，申请证书：

```bash
sudo certbot --nginx -d ops.example.com
```

如需手动使用模板：

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/xlx-elderly-ops.conf
sudo sed -i 's/your-domain.example.com/ops.example.com/g' /etc/nginx/sites-available/xlx-elderly-ops.conf
sudo ln -s /etc/nginx/sites-available/xlx-elderly-ops.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

公网访问地址：

```text
https://ops.example.com
```

手机端直接用浏览器打开同一地址即可。

## 6. 防火墙

公网只开放 HTTP/HTTPS：

```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
sudo ufw status
```

不要开放 PostgreSQL 的 `5432` 端口，也不要开放 Node 的 `8787` 端口。Node 服务只监听 `127.0.0.1:8787`。

## 7. 服务管理

查看状态：

```bash
sudo systemctl status xlx-elderly-ops
```

重启服务：

```bash
sudo systemctl restart xlx-elderly-ops
```

查看日志：

```bash
sudo journalctl -u xlx-elderly-ops -f
```

## 8. 数据备份

手动备份：

```bash
cd /opt/xlx-elderly-ops
bash scripts/backup_db.sh
```

建议配置每日自动备份：

```bash
sudo crontab -e
```

加入：

```cron
15 2 * * * cd /opt/xlx-elderly-ops && bash scripts/backup_db.sh >> /var/log/xlx-elderly-ops-backup.log 2>&1
```

备份文件默认保留最近 30 天。

## 9. 数据恢复

恢复前先停止服务并做当前备份：

```bash
sudo systemctl stop xlx-elderly-ops
cd /opt/xlx-elderly-ops
bash scripts/backup_db.sh
bash scripts/restore_db.sh backups/某个备份文件.sql.gz
sudo systemctl start xlx-elderly-ops
```

## 10. 安全要求

- 管理员初次登录后必须修改密码。
- 禁用不需要的演示账号。
- 所有公网访问必须走 HTTPS。
- PostgreSQL 和 Node 服务不得直接暴露公网。
- `.env` 权限应保持 `600`。
- 定期下载数据库备份到异地保存。
- 员工离职后立即禁用账号。
